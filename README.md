# ربات کلاس‌های زوج و فرد

ربات Python آماده برای مدیریت کلاس‌های تلگرام، بررسی عضویت گروه و کانال‌ها، راهنمای خصوصی، سهمیه پیام، حذف زمان‌دار و گزارش روزانه است.

در خصوصی ربات Start بزنید. منوی شاگرد سه انتخاب دارد: **راهنمای کلاس‌ها**، **آموزش در YouTube** و **راهنمای ربات**. راهنمای ربات، شیوه ارسال تکلیف و قوانین پیام را توضیح می‌دهد. مدیر اصلی دکمه **تنظیمات راهنما** را هم دارد و ساعت‌ها و لینک‌های فرد و زوج را بدون انتشار دوباره تغییر می‌دهد. [راهنمای منو](MENU-fa.md)

تکلیف را در گروه کلاس خود با `H.W` در ابتدای متن یا کپشن بفرستید؛ مانند `H.W تمرین جلسه ۵`. تکلیف پذیرفته‌شده خودکار حذف نمی‌شود، ولی عضویت لازم دارد و از سهمیه پیام کلاس حساب می‌شود. در آلبوم، هر عکس یا فایل یک پیام است و کپشن همان فایل باید با `H.W` شروع شود.

**اجرای آنلاین:** [راهنمای کامل فارسی هاست](HOSTING-fa.md) مسیر Render Free، دیتابیس پایدار Turso و کارهای زمان‌دار cron-job.org را توضیح می‌دهد. فایل `render.yaml` برای ساخت سرویس آماده است. توکن و رمزها را در Environment وارد کنید؛ فایل‌های محرمانه را آپلود نکنید.

**اجرای روی کامپیوتر:** [راهنمای محلی](README-fa.md)، [راهنمای ویندوز](WINDOWS-fa.md) و [راهنمای Android](ANDROID-fa.md).

نصب ابری از `config.hosted.json` شروع می‌شود. کلاس‌های اضافه‌شده، سهمیه‌ها و صف حذف‌ها در دیتابیس خارجی حفظ می‌شوند. ابزار `migrate_to_cloud.py` انتقال اختیاری سابقه محلی را انجام می‌دهد.

پلن‌های رایگان محدودیت مصرف و احتمال توقف دارند؛ جزئیات و منابع رسمی در راهنمای هاست آمده‌اند.
